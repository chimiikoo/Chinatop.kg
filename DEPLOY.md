# Инструкция по загрузке сайта на хостинг (Plesk)

Поздравляю с покупкой хостинга! Ваша панель управления (Plesk) очень удобная и позволяет легко запустить современные сайты на Node.js.

Вот пошаговая инструкция, что нужно сделать:

## Шаг 1: Подготовка файлов (на вашем компьютере)

Вам нужно собрать проект, чтобы получить готовую папку `dist`.

1.  Откройте терминал в папке проекта (VS Code -> Terminal -> New Terminal).
2.  Выполните команду:
    ```bash
    npm run build
    ```
    *(Если вы используете pnpm, то `pnpm run build`)*.
3.  После успешного выполнения появится папка `dist`.

## Шаг 2: Архив для загрузки

Соберите в один ZIP-архив следующие файлы и папки из корня вашего проекта:

1.  Папку `dist` (целиком).
2.  Файл `package.json`.
3.  Файл `pnpm-lock.yaml` (или `package-lock.json`, если есть).

**Не загружайте папку `node_modules`!** Она весит очень много и должна устанавливаться на самом сервере.

## Шаг 3: Загрузка на хостинг

1.  Зайдите в панель управления Plesk (по ссылке `plesk.truedomain.info`, логин и пароль должны быть в письме от хостера).
2.  Найдите раздел **"File Manager"** (Файлы) для вашего домена.
3.  Перейдите в папку `httpdocs` (это корневая папка вашего сайта).
4.  Удалите оттуда стандартные файлы (обычно там файл `index.html` с заглушкой "Under Construction").
5.  Нажмите кнопку **"Upload"** и выберите ваш ZIP-архив.
6.  После загрузки выберите архив галочкой и нажмите **"Extract Files"** (Распаковать).
7.  Убедитесь, что файлы лежат прямо в `httpdocs`, а не в подпапке. Структура должна быть такой:
    *   `httpdocs/dist/...`
    *   `httpdocs/package.json`
    *   `httpdocs/pnpm-lock.yaml`

## Шаг 4: Настройка Node.js в Plesk

1.  Вернитесь на главную страницу домена в Plesk.
2.  Найдите иконку **"Node.js"** (если её нет, нажмите "Show More" или найдите в поиске справа вверху).
3.  Включите Node.js, если он выключен ("Enable Node.js").
4.  Настройте параметры:
    *   **Node.js Version**: выберите версию **18** или **20** (желательно 20, если есть).
    *   **Document Root**: оставьте `httpdocs`.
    *   **Application Mode**: переключите на **Production**.
    *   **Application Startup File**: укажите `dist/index.js`.
5.  Нажмите кнопку **"NPM Install"** (это установит все нужные библиотеки на сервере). Подождите окончания процесса.
6.  Нажмите кнопку **"Restart App"** (Перезапустить приложение).

## Проверка SSL
Вы упомянули, что SSL обрабатывается. В Plesk обычно есть раздел **"SSL/TLS Certificates"**.
1.  Зайдите туда.
2.  Если сертификат еще не активен, нажмите **"Reissue Certificate"** или "Install free basic certificate provided by Let's Encrypt".
3.  Убедитесь, что галочка "Examples: Secure webmail..." тоже стоит (для почты).
4.  Нажмите "Get it free".

## Если сайт не открывается
Если после всех шагов вы видите ошибку `500` или `502`:
1.  В настройках Node.js в Plesk часто есть кнопка "View Logs" (Посмотреть логи). Нажмите её, чтобы увидеть причину ошибки.
2.  Убедитесь, что в файле `package.json` (который вы загрузили) в секции `scripts` есть команда `start`, которая запускает `node dist/index.js`. (Мы её уже настроили, но проверьте).

---
**Готово!** Теперь ваш сайт должен работать по адресу вашего домена.
